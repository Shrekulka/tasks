# Профили языков ответа

Один файл на язык: `<код>.json`. Код выбирается переменной `ANSWER_LANGUAGE`, каталог задаёт
`LANGUAGE_PROFILES_DIR`. Чтобы добавить язык, положите сюда файл с теми же полями:

| Поле | Смысл |
|---|---|
| `code` | код языка, совпадает с именем файла |
| `scripts`, `main_script` | допустимые письменности (первое слово имени символа в Unicode) и основная |
| `answer_phrase` | как попросить этот язык в промпте, на языке промпта (для uk: «українською мовою»); подставляется в системный промпт и строгий повтор |
| `min_script_share` | минимальная доля букв основной письменности |
| `own_letters` | буквы, которые есть в языке и обычно встречаются в тексте |
| `foreign_letters` | буквы близкого языка, которых в этом языке нет |
| `own_words` | частые служебные слова только этого языка |
| `foreign_words` | частые служебные слова близкого языка, которых в этом языке нет |

Тексты промптов лежат отдельно, в `data/prompts/` (см. README там). Это эвристика, а не детектор языка. Качество проверяется тестом `tests/unit/test_language_corpus.py`
на размеченных примерах `tests/eval/language_cases.json`: пополняйте их реальными ответами моделей.
