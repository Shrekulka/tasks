# Тексты промптов

Промпты лежат в файлах, а не в коде: правка текста не требует изменения Python.

| Файл | Назначение |
|---|---|
| `system.txt` | системный промпт ответа |
| `strict_reminder.txt` | добавка к запросу для одного строгого повтора (ТЗ §12) |

В тексте работает один плейсхолдер `$answer_phrase`: фраза языка ответа из профиля
`data/languages/<код>.json` (поле `answer_phrase`). Остальной текст попадает в модель как есть,
поэтому фигурные скобки JSON экранировать не нужно. Знак доллара вне плейсхолдера пишите `$$`.

**Свой промпт для языка.** Положите `data/prompts/<код>/system.txt` (и при желании `strict_reminder.txt`):
файл языка важнее общего. Версия промпта в ключе кэша ответов считается по итоговому тексту, поэтому
правка файла сама сбрасывает кэш.

Каталог задаёт `PROMPTS_DIR`. Тексты интерфейса бота (ответы пользователю) лежат отдельно, в `lexicon/`.
