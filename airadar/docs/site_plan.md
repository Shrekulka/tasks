# План сайту AI Radar

## Мета
Знаходити нові AI-проєкти за хвилини, а не за години ручного пошуку: бачити, що з'явилося в індексі, відфільтрувати за нішею, білдером і DR, порівняти кандидатів і вивантажити добірку.

## Аудиторія та сценарії
| Хто | Задача | Шлях сайтом |
|---|---|---|
| Інвестор / скаут | Побачити нові AI-проєкти в ніші, відібрати кандидатів | `/` → клік по ніші → `/catalog/?niche=…&dr_min=…` → «Порівняти» |
| SEO-фахівець / маркетолог | Знайти сайти з потрібним білдером чи TLD для аналізу конкурентів | `/catalog/?ai_source=…&tld=…` → CSV |
| Дослідник | Оцінити розмір і динаміку ринку, знайти схожі проєкти | `/` (KPI, графіки) → `/site/<домен>/` → «Схожі сайти» |

**Критерій успіху:** від відкриття сайту до CSV з відфільтрованою добіркою менше 2 хвилин, без реєстрації.

## Структура сайту
```
/                 KPI (AI-сайти, +за 7/30 днів, дата статистики), свіжі сайти, графіки
├─ /catalog/      пошук, фільтри (ніша, білдер, TLD, DR, період), сортування, «Показати ще», CSV
│   ├─ /site/<домен>/   картка сайту + «Схожі сайти» (та сама ніша)
│   └─ /catalog/export.csv   до 100 рядків з тими самими фільтрами
├─ /compare/?d=a&d=b      таблиця 2–3 сайтів (+ необов'язковий AI-вердикт, P2)
│   └─ /compare/verdict/  POST, лише при наявності ключів OpenRouter
└─ /about/        методологія й обмеження даних
```

## Дані (FreeSerp API, `index=sites`, `ai_startups=1`)
| Блок | Запит | Примітка |
|---|---|---|
| Каталог, свіжі, схожі | `sort`, `ai_categories`, `ai_source`, `tld`, `dr_min/dr_max`, `from_date`, `q` | `q` без `sort` = релевантність |
| Картка / порівняння | `q=<домен>&all=1` | точний збіг домену |
| Списки фільтрів | `stats=1` (`top_ai_categories`, `top_ai_source`, `top_tld`) | не хардкодяться; ніші повністю |
| KPI та графіки | `stats=1` + `total` з `size=1` | `by_day` = весь індекс; DR та +7/30 днів рахуються по AI окремо |

## Обмеження
Дані автоматичні й «шумлять»; `went_live` ≠ дата запуску; новим доменам DR ще не оцінено; пагінація до 10 000 записів (`from + size`); пошук кешується 1 хв, статистика 15 хв.

Структура: Browser → Django (форми, валідація, нормалізація, кеш, ретраї) → FreeSerp.
